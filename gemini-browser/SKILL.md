# Gemini 网页图片与视频生成

使用本 Skill 的 Python 工具操作 `gemini.google.com`，不调用 Gemini API。浏览器复用本地独立配置目录保存登录态；网页功能及额度以当前账号实际页面为准。

## 固定工作流

用户要求固定生成流程、把自然语言整理为可重复调用的模板，或让外部 Agent 创建/执行流程时，读取 [工作流说明](references/workflows.md)。将步骤、提示词、参考图和变量写成规范，使用 `workflow create` 注册并完成 `validate`、`plan`；用户要求运行或生成时再执行 `run`，不自行拼接未声明的功能。

- 只要求创建或修改流程时，交付配置和计划即可，不自动生成媒体。用户已要求运行时，按其要求执行，不重复索取确认。

- 工作流只含按顺序执行的 `image` / `video` 步骤。参考图可以是固定本地素材，或前面图片步骤的输出。每步下载校验成功且聊天删除确认后，才执行下一步；失败停止，不自动重试或复用旧聊天。
- `create`、`list`、`show`、`validate`、`plan` 和 `run --dry-run` 只操作本地文件，不打开浏览器。`workflow result RUN_ID` 只查本地工作流运行；媒体步骤仍使用本 Skill 的单任务执行与精确清理规则。
- 外部 Agent 需要能访问运行本 Skill 的电脑及其脚本、素材和输出目录。纯云 Agent 不会因此自动获得本机浏览器或登录态访问能力。
- 模板固定流程、素材和生成约束，不能保证每次生成的像素完全相同。工作流完整实测须另有证据，不能由下层单图或单视频已通过推断。

## 执行流程

1. 首次使用先读取 [使用说明](references/usage.md)，运行 `scripts/gemini_browser.py --help` 及相应子命令的 `--help`，确认当前工具参数。依赖缺失时按本 Skill 的 `requirements.txt` 安装。
2. 运行 `status` 检查登录状态。`login_required` 时运行 `login`，告知用户已打开窗口，需要在窗口内完成 Google 登录与验证；保留等待进程，等待成功状态。`loading` 或连接错误表示尚未确认，按使用说明检查网络或页面，不据此断言未登录。不要让用户在聊天中提供密码或验证码。
3. 整理一条完整提示词并保留用户指定的内容、文字、风格、比例及动作。文生图或图生图使用 `image`；图生图用可重复的 `--reference PATH` 指定本地参考图。图生视频使用 `video`，至少提供一张参考图，`--reference` 同样可重复。提示词用 `--prompt` 或 UTF-8 `--prompt-file` 二选一。
4. 每任务确认新建独立聊天；有参考图时先上传，再选择可用的图片或视频工具，发送前重新确认附件预览完整且发送按钮可用，只提交一次。未找到视频工具入口时，可通过明确的视频提示词请求生成，但仍只接受真实视频结果。等待原生下载、校验本地媒体并删除该任务聊天。不复用旧聊天继续生成或下载，不把上传缩略图当生成结果。
5. 完成条件是本地媒体校验通过，且任务记录的 `chat_cleanup` 确认聊天已删除。报告实际文件路径；文件已保存但清理失败时如实报告部分完成，保存任务 ID，按下节补删，不默默报成功。能力入口、视频长度、套餐与额度以实际页面为准；未取得图生图或图生视频的真实成功证据时，不声称已跑通。

## 本地结果与补删

- `result RUN_ID` 只重新校验已保存的本地图片或视频，不打开网页、不恢复下载、不重新生成。
- `cleanup RUN_ID` 只补删该任务记录指向的聊天。默认仅删除本工具确认新建并记录的该任务聊天，不清空其他聊天；用户已授权每任务删除，无需重复确认。
- 正常失败和 Ctrl+C 退出也会尝试删除。外部强杀、断网、登录失效或页面变化可能阻止清理；`chat_cleanup` 失败时明确告知用户，保留任务 ID，条件恢复后用 `cleanup` 补删。
- 无法唯一确认目标聊天时，不猜测删除对象。多条模型回复等异常会停止自动下载；说明已保存的结果和清理状态，不重新提交提示词。
- 超时不等于未提交，不自动重试生成任务。需要重做时创建全新任务，仍执行新建聊天与结束删除。

## 登录态与当前范围

- 登录态只保存在本机独立 profile。不得读取、记录、打印或上传密码、cookies、令牌和 profile 内容；不得将 profile 放入版本库。
- 同一 profile 同时只由一个本工具进程使用。登录态过期时重新执行人工登录流程。
- 当前命令覆盖登录持久化、文生图、图生图、图生视频、固定顺序工作流、查看本地结果与任务聊天补删。重复 `--reference` 表示同一任务的多张参考图；批量、循环、调度、视频文件作为输入及自动提示词批量组合不在当前范围。
- 本地媒体与任务记录在删除网页聊天后保留。未取得媒体校验与聊天删除的成功证据时，只报告已完成部分和剩余事项；不承诺程序崩溃时聊天也一定删除。
